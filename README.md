## 🧠 Overview

This is a simple **Tic Tac Toe (X-O)** game built using **HTML, CSS, and Vanilla JavaScript**.  
The project focuses on practicing **DOM manipulation, event handling, and core JavaScript logic**.

Players take turns placing X and O on a 3x3 grid until a player wins or the game ends in a draw.

---

## 🎮 Features

- Two-player mode (X and O)
- Player vs Computer mode
- Turn-based gameplay system
- Win detection (rows, columns, diagonals)
- Draw detection when no moves are left
- Reset game functionality
- Interactive UI with real-time updates
